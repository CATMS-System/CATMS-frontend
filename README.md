# CATMS Frontend Service

Web client for the Clinic Appointment and Treatment Management System (CATMS).

## Overview

The frontend interface provides operational interfaces for clinic staff, doctors, patient portal views, and management reporting dashboards.

## Setup Instructions

### 1. Prerequisites
- Node.js 18+
- npm or pnpm

### 2. Documentation
Refer to `docs/` for technical structure:

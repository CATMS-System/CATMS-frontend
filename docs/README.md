# CATMS Frontend Documentation

This directory contains technical documentation for the CATMS web client interface.

## Documentation Structure

- `architecture.md`: Frontend architecture, component hierarchy, and routing.
- `state-management.md`: Client state management and API integration layers.
- `setup.md`: Local development environment setup, build scripts, and execution instructions.
- `testing.md`: Quality assurance verification flows and testing procedures.

Documentation will be expanded incrementally alongside frontend development.
